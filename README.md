# ZINA UF — webbutikens startprojekt

En responsiv, färgstark webbshop för ZINA UF:s handgjorda pärlhalsband. Byggd med HTML, CSS och JavaScript utan ramverk.

## Kom igång
1. Packa upp projektmappen.
2. Öppna `index.html` i webbläsaren, eller använd tillägget **Live Server** i Visual Studio Code.
3. Redigera produktlistan i `script.js` med era riktiga halsband, beskrivningar och priser.
4. Byt ut `BYT-TILL-ER-EPOST@EXEMPEL.SE` i `script.js` till företagets ordermejl.

## Funktioner
- Mobilanpassad startsida
- Produktkort och kategori-filter
- Varukorg med antal och summa
- Beställningsformulär som skapar en orderförfrågan
- FAQ och presentation av ZINA UF

## Viktigt innan lansering
Det här är en front-end-prototyp. Den tar **inte** emot betalningar och lagrar inte beställningar på en server. För riktig e-handel behöver ni en säker lösning för orderhantering och betalning, till exempel en etablerad e-handelsplattform eller en backend med lämplig betaltjänst. Bekräfta även leveransvillkor, retur/reklamationsinformation, integritetspolicy och kontaktuppgifter innan ni tar emot beställningar.

Illustrationerna av halsband är grafiska platshållare. Byt gärna ut dem mot egna foton av era faktiska produkter.
